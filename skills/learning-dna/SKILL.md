# 学习DNA

## 概述

学习DNA 是整个 AI 辅助学习系统的"中枢"。它建立并维护一份学生的个性化学习档案，
让后续所有学习技能都能基于学生的真实情况做出个性化响应，而不是套用通用模板。

## 核心理念

不是"帮孩子找答案"，而是"帮孩子认识自己怎么学"。
一份好的学习DNA让孩子看见：我擅长什么、我在哪里卡住、我的目标是什么、我进步了多少。

## 工作流程

### 1. 首次建立学习DNA

当学生说"帮我建立学习DNA"或首次使用学习系统时，通过对话收集以下信息：

**基础信息：**
- 姓名/昵称
- 年级/学段（小学/初中/高中/大学）
- 目前学习的学科

**学习风格：**
- 偏好视觉学习 / 听觉学习 / 动手实操 / 阅读笔记？（四选一或多选）
- 一天中哪个时段学习效率最高？（早晨/下午/晚上）
- 集中注意力的时长？（25分钟/45分钟/更长）

**学科画像（按学科逐一填写）：**
- 当前掌握程度（1-5分自评）
- 最擅长什么题型/模块？
- 最怕什么题型/模块？
- 近期目标分数/等级

**学习目标：**
- 短期目标（本月/本学期）
- 长期目标（升学/竞赛/兴趣）

**可用时间：**
- 工作日每天可用学习时间
- 周末每天可用学习时间

收集完成后，将信息结构化保存到 `~/.workbuddy/learning-dna/profile.md`。

保存格式示例：

```markdown
# 学习DNA档案

## 基础信息
- 姓名：小明
- 年级：初二
- 学科：语文、数学、英语、物理

## 学习风格
- 偏好：视觉学习 + 动手实操
- 最佳时段：晚上 19:00-21:00
- 专注时长：45分钟

## 学科画像
### 数学
- 掌握程度：3/5
- 擅长：代数运算、方程求解
- 薄弱：几何证明、函数图像
- 目标：期中考试 85 分

### 英语
- 掌握程度：3/5
- 擅长：阅读理解
- 薄弱：完形填空、写作
- 目标：期末 90 分

## 学习目标
- 短期：本学期期中数学上 85，英语上 90
- 长期：中考目标重点高中

## 可用时间
- 工作日：2小时/天
- 周末：4小时/天

---
最后更新：YYYY-MM-DD
```

### 2. 更新学习DNA

随着学习推进，学生可以随时更新DNA中的任何部分：

- "我数学几何进步了，更新一下DNA"
- "我最近发现早上学习效率更高"
- "期中考试结束了，更新我的目标"

更新时：
1. 先读取现有档案
2. 让学生确认要更改的内容
3. 更新对应条目并保留更新记录（在档案末尾增加版本行）

### 3. 被其他技能引用

学习DNA 是一个被动技能，主要被其他技能调用：

- **智能错题本**：根据DNA中的学科薄弱点，标注错题优先级
- **费曼学习法**：根据DNA中的学习风格，调整验证方式
- **每周复盘**：从DNA中读取目标，对照实际进展
- **学习计划**：根据可用时间生成合理的学习计划

其他技能加载学习DNA时，使用 `Read` 工具读取 `~/.workbuddy/learning-dna/profile.md`。

## 重要原则

1. **鼓励自我认知**——不是替学生填写，而是通过提问引导他们自己说出口
2. **保持动态**——DNA 不是写死的，要随学习进展不断更新
3. **尊重隐私**——档案保存在本地，不离开学生设备
4. **正向引导**——关注"你哪里进步了"而不是"你哪里不行"
