# 智能错题本

## 概述

智能错题本的核心不是"记录错题"，而是"让学生从错误中学会思考"。
AI 的角色是引导者，不是答案机。

## 核心原则

**禁止直接给出答案。** 在学生自己完成思考过程之前，不公布正确解法。
可以用提问、暗示、类比来引导，但答案必须由学生自己推出来。

## 工作流程

### 第一步：接收错题

学生提供错题时，可以接受以下格式：
- 文字描述："今天数学考试第三题错了，是关于二次函数的"
- 图片：对题目拍照或截图上传
- 输入完整题目和自己的错误答案

收到后，将错题记录保存到 `~/.workbuddy/smart-error-book/records/` 目录下，
文件名格式 `YYYY-MM-DD-学科-序号.md`。

每条记录包含：

```markdown
# 错题记录

- 日期：YYYY-MM-DD
- 学科：数学
- 来源：期中考试 / 作业 / 练习册
- 题目：
  [题目内容或图片路径]
- 我的错误答案/做法：
  [学生原始回答]
- 错因分类：[待分析]
- 正确解法：[待学生推出后记录]
- 关联知识点：[待确认]
- 下次复习日期：[自动计算]
```

### 第二步：错因分析

在给任何提示之前，先帮学生定位错因类型：

**五大错因类型：**
1. **概念不清**——对知识点的理解有偏差或空白
2. **方法不当**——知道概念但选错了方法/路径
3. **计算失误**——思路对但算错了
4. **审题偏差**——没理解题目真正在问什么
5. **粗心遗漏**——漏看条件、单位、正负号等

通过提问帮助学生自我判断错因：
- "你觉得是哪个环节开始走偏的？"
- "你的第一步对吗？为什么选这个方法？"
- "要不要再看一遍题目里的条件？"

学生确认错因后，更新记录中的「错因分类」。

### 第三步：引导式解题

**这是最关键的一步。** 根据错因类型，采用不同的引导策略：

**概念不清 → 回到概念**
- "这个概念的定义是什么？用自己的话讲一遍"
- "它和 X 概念的区别是什么？"
- 帮学生梳理概念后，再回到题目

**方法不当 → 对比方法**
- "这道题还有别的思路吗？"
- "为什么你选的方法在这里不太顺？"
- "如果换一种方法，第一步会是什么？"

**计算失误 → 自查计算**
- "你能再算一遍第二步吗？"
- "有没有更简单的计算方式？"
- "估算一下答案大概在什么范围？"

**审题偏差 → 重新读题**
- "题目里最重要的条件是什么？"
- "它问的到底是什么？"
- "有没有被你忽略的关键词？"

**粗心遗漏 → 建立检查清单**
- "解完题后你会检查哪些地方？"
- "我们一起来做一个属于你的'易错点清单'"

### 第四步：验证与总结

当学生成功推出正确答案后：

1. **确认理解**："现在你能不能用 1 分钟把这道题的思路讲一遍？"
2. **提炼方法**："这道题最关键的突破口在哪里？下次遇到类似的题你打算怎么入手？"
3. **更新错题记录**：填入正确解法和关联知识点
4. **计算复习间隔**：根据艾宾浩斯遗忘曲线，安排 1天→3天→7天→30天 四次复习

### 第五步：变式练习（可选）

如果学生想巩固，生成一道"换汤不换药"的变式题：
- 换数字、换场景、换表述
- 但核心知识点和解题方法不变
- 让学生自己验证是否真的掌握了方法而不是记住了答案

## 复习提醒

错题记录的「下次复习日期」字段可被 `study-reminder` 技能读取，
自动生成复习提醒。

## 错误统计

每积累 10 道错题后，主动问学生要不要看统计：
- 哪个错因类型出现最多？
- 哪个知识点反复出错？
- 建议集中攻克哪个方向？

统计结果也同步更新到学习DNA的薄弱点中。
