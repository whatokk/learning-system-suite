# IM提醒

## 概述

学习提醒系统帮助学生建立规律的学习节奏，而不是靠"想起来才学"。
底层基于 WorkBuddy 的 automation 机制，支持一次性提醒和周期性提醒。

## 核心理念

最好的提醒不是"催你学习"，而是"帮你建立习惯"。
提醒应该像一个友善的同学拍了拍你的肩膀，而不是一个严厉的闹钟。

## 提醒类型

### 1. 错题复习提醒

根据智能错题本中的复习计划，自动生成提醒：

- 第1次复习：错题录入后 1 天
- 第2次复习：第1次复习后 3 天
- 第3次复习：第2次复习后 7 天
- 第4次复习：第3次复习后 30 天

通过读取 `~/.workbuddy/smart-error-book/records/` 目录中的错题文件，
扫描「下次复习日期」字段，为到期的错题生成提醒。

### 2. 每日学习提醒

固定的每日学习时间段提醒：
- "晚上 7 点了，今天的数学练习准备好了吗？"
- "早上 7:30，背 10 个单词时间到"

可以设置多个学科的固定时间。

### 3. 作业/考试截止提醒

一次性提醒：
- "下周三物理作业截止，你还有 3 天"
- "距离期中考试还有 2 周，你的复习计划跟上了吗？"

### 4. 费曼学习提醒

每周固定时间提醒做一次费曼学习：
- "这周学了二次函数，要不要找个人讲一遍？"

### 5. 复盘提醒

每周日晚上提醒进行每周复盘。

## 如何使用

### 创建提醒

学生用自然语言说出提醒需求，AI 将其转换为 automation：

示例对话：
- 学生："每天晚上7点提醒我做数学练习"
- AI：创建一个每日 19:00 触发的 automation

- 学生："下周五下午3点提醒我交物理作业"
- AI：创建一个一次性 automation，scheduledAt 为下周五 15:00

### 管理提醒

- "我有哪些提醒？" → 列出所有活跃的 automation
- "取消数学练习提醒" → 找到对应 automation 并删除
- "把英语单词提醒改到早上7点" → 更新对应 automation 的时间

### 实现方式

使用 `automation_update` 工具创建提醒：

**一次性提醒示例：**
```
automation_update({
  mode: "create",
  name: "物理作业截止提醒",
  prompt: "提醒学生：物理第三章作业明天截止，请检查是否完成。
           如果已完成，可以问问学生有没有不懂的题目需要记录到错题本。",
  scheduleType: "once",
  scheduledAt: "2026-08-15T15:00:00"
})
```

**周期性提醒示例：**
```
automation_update({
  mode: "create",
  name: "每日数学练习提醒",
  prompt: "用友善的语气提醒学生开始数学练习。
           先询问今天数学课学了什么新内容，
           然后问有没有作业或错题需要处理。
           如果学生说不想做，温和地鼓励：'做一道也行，开始了就不难了。'",
  scheduleType: "recurring",
  rrule: "FREQ=DAILY;BYHOUR=19;BYMINUTE=0"
})
```

## 提醒设计原则

1. **友善不施压**——用"要不要开始？"而不是"你该学习了！"
2. **提供入口**——提醒不只是通知，而是直接提供下一步行动的选择
3. **灵活可调**——学生可以随时说"今天不想学"或"改到明天"
4. **正向反馈**——学生完成学习后，给一句鼓励而不是沉默
5. **关联其他技能**——复习提醒自动读取错题本数据，不是孤立存在

## 与其他技能的协作

- **智能错题本**：自动读取错题复习日期，生成复习提醒
- **每周复盘**：每周日自动提醒进行复盘
- **学习DNA**：根据学生的可用时间，把提醒安排在最佳学习时段
