# 提醒模板与话术

## 每日学习提醒

```
名称：每日[学科]学习提醒
触发时间：学生指定的时间
话术：
"嘿，今天的[学科]时间到了。

你今天打算先做什么？
- [ ] 复习昨天的错题
- [ ] 做今天的作业
- [ ] 预习明天要讲的内容

[学生姓名]加油，开始了就成功一半~"
```

## 错题复习提醒

```
名称：错题复习提醒
触发时间：根据艾宾浩斯曲线自动计算
话术：
"有 X 道错题到了该复习的时间了。

上次你在这几道题上卡住了：
- [知识点1]（第N次复习）
- [知识点2]（第N次复习）

要不要挑一道来试试？看看这次能不能顺利做出来？"
```

## 单词背诵提醒

```
名称：每日单词背诵
触发时间：早晨或学生指定时间
话术：
"早！今天的 10 个单词准备好了：
[单词列表]

目标：能默写、能用每个词造一个句子。

预计时间：15 分钟。准备好了就开始吧！"
```

## 费曼学习提醒

```
名称：每周费曼学习
触发时间：固定一天（如周三晚）
话术：
"又到了'当小老师'的时间了！

这周你学了[知识点]，要不要试着讲给我听？
规则还记得吗：
1. 用自己的话讲
2. 不能照搬课本
3. 要让我这个'外行'也听懂

准备好了吗？"
```

## 每周复盘提醒

```
名称：每周学习复盘
触发时间：周日晚 20:00
话术：
"一周结束啦，来花 20 分钟回顾一下吧。

这周你学到了什么？做对了什么？做错了什么？下周想怎么调整？

准备好了就说'开始复盘'~"
```

## 作业截止提醒

```
名称：[作业名称]截止提醒
触发时间：截止前 1-3 天
话术：
"[作业名称]还有[X]天就要交了。

进度怎么样？
- [ ] 还没开始 → 没关系，现在开始也不晚
- [ ] 做了一半 → 需要帮忙吗？
- [ ] 快完成了 → 别忘了检查一遍

有不懂的题目可以随时问我，我们一起分析。"
```

## 考试倒计时提醒

```
名称：[考试名称]倒计时提醒
触发时间：考前 2周/1周/3天/1天
话术（2周前）：
"距离[考试名称]还有 2 周。

现在的进度：
- 已复习：[已覆盖的知识点]
- 易错点：[根据错题本统计]
- 还没复习：[未覆盖的知识点]

建议先把错题本过一遍，再针对薄弱点做专项练习。
要现在制定一个复习计划吗？"

话术（1天前）：
"明天就是[考试名称]了。

今天不要学新东西了——把你最容易犯的 3 种错再看一遍就好。
早点睡，明天轻松上阵。你准备得挺好的。"
```

## 提醒话术原则

1. **以"你"开头**——让学生感觉这是对自己说的，不是群发的
2. **给选项不给压力**——"要不要"而不是"你必须"
3. **数据说话**——引用错题本/学习DNA的实际数据
4. **正向结尾**——每条提醒以鼓励收尾
5. **有下一步**——不只是通知，直接告诉学生该做什么
