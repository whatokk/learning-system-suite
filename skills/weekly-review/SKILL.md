# 每周复盘

## 概述

每周复盘是整个学习系统的"闭环"环节。它不只是回顾"学了什么"，
而是把错题、费曼笔记、学习计划、学科进展串联起来，
让学生看到：**我这一周到底在进步什么，下周该往哪里走。**

## 核心理念

复盘的目标不是"算账"（你这周为什么没完成计划），
而是"导航"（你现在在哪，接下来去哪）。

## 工作流程

### 第一步：数据收集

复盘前，AI 自动读取相关数据：

1. **错题本** → 读取本周新增的错题
   - 路径：`~/.workbuddy/smart-error-book/records/`
   - 筛选条件：日期在本周范围内的记录
   - 关注：新增了多少题？错因分布如何？哪些已复习？

2. **费曼学习记录** → 读取本周的费曼笔记
   - 路径：`~/.workbuddy/feynman-learning/notes/`
   - 关注：搞懂了几个概念？还有哪些漏洞没补？

3. **学习DNA** → 读取当前目标和进度
   - 路径：`~/.workbuddy/learning-dna/profile.md`
   - 关注：目标有变化吗？学科掌握程度需要更新吗？

4. **上周复盘记录** → 读取上周定的计划
   - 路径：`~/.workbuddy/weekly-review/archives/`
   - 关注：上周列的计划，完成了多少？

### 第二步：引导式回顾

AI 以对话形式带着学生回顾这周，每问一个问题给足思考时间：

**Q1：这周学了什么？（知识盘点）**
- "这周各科都学了哪些新内容？"
- "哪个知识点你觉得最有意思？"
- "哪个让你觉得最难？"

**Q2：错题情况怎么样？（薄弱点追踪）**
- "这周新增了 X 道错题，主要集中在 [错因类型] 上"
- "你觉得为什么这个类型的题容易错？"
- "有没有一个错题，你复盘之后觉得'原来如此'？"

**Q3：哪些是真懂了？（费曼检验）**
- "这周你用费曼法搞懂了几个概念？"
- "有没有哪个概念你觉得自己讲得特别清楚？"
- "还有没有你觉得自己可能没真懂的地方？"

**Q4：学习习惯如何？（元认知）**
- "这周学习时间够不够？"
- "哪个时段效率最高？哪个时段容易走神？"
- "有什么干扰因素吗？（手机、困、不知道从哪开始）"

**Q5：有什么开心的？（正向激励）**
- "这周学习中有没有让你觉得'我还挺厉害'的瞬间？"
- "有没有老师或同学表扬你的地方？"
- "学到了什么让你觉得'哇这个好有意思'的东西？"

### 第三步：数据可视化

帮学生把一周的数据变成直观的总结：

```markdown
# 第X周学习复盘 (YYYY-MM-DD ~ YYYY-MM-DD)

## 数据总览
| 指标 | 数值 |
|------|------|
| 新增错题 | X 道 |
| 已复习错题 | X 道 |
| 费曼学习 | X 个知识点 |
| 未补漏洞 | X 个 |
| 实际学习时长 | 约 X 小时 |

## 错因分布
- 概念不清：XX%
- 方法不当：XX%
- 计算失误：XX%
- 审题偏差：XX%
- 粗心遗漏：XX%

## 本周亮点
- [学生提到的得意瞬间]

## 本周发现
- [学生意识到的学习规律或问题]

## 下周计划
- [具体的、可量化的下周目标]
```

### 第四步：制定下周计划

基于复盘结果，和学生一起制定下周的具体行动：

**计划要 SMART：**
- Specific（具体）："每天做 5 道几何证明题"而不是"数学多练练"
- Measurable（可衡量）：有明确的数字或完成标准
- Achievable（可实现）：别定不可能完成的目标
- Relevant（相关）：紧扣本周发现的薄弱点
- Time-bound（有时限）：一周后能看到结果

**示例：**
- "下周每天睡前用 10 分钟回顾当天的错题"
- "下周三前用费曼法搞懂二次函数图像变换"
- "下周四做一次英语完形填空的专项练习（限时 20 分钟）"

### 第五步：更新学习DNA

复盘发现的长期变化，同步更新到学习DNA：
- 某个学科的掌握程度是否提升了？
- 有没有发现新的薄弱点？
- 目标是否需要调整？

### 第六步：存档

将复盘报告保存到 `~/.workbuddy/weekly-review/archives/YYYY-WXX.md`。

同时在 `~/.workbuddy/weekly-review/summary.md` 中维护一份滚动总结，
记录每周的关键进展，方便长期追踪。

## 复盘频率建议

- **周复盘**：每周日晚 30 分钟（核心）
- **月复盘**：每月最后一天 1 小时（回顾本月趋势，调整长期计划）
- **学期复盘**：期中/期末各一次（对标考试目标，全面评估）

## 与其他技能的协作

- **学习DNA**：复盘结果回写DNA，保持档案的准确性
- **智能错题本**：复盘时发现的新漏洞，可以批量创建错题记录
- **费曼学习法**：下周计划中可以指定用费曼法攻克的概念
- **IM提醒**：根据下周计划自动设置对应的学习提醒
